# 🎯 My Way - Task Management Web App

A web application built with Flask and Python that helps users manage their goals through a structured system of projects and tasks, with a gamified progress system.

## 🚀 Features

- User authentication (register/login)
- Goal → Project → Task hierarchy
- Progress tracking with points and levels
- Clean and simple user interface
- SQLite database integration

## 💡 Description

This application allows users to break down their goals into smaller, manageable steps.

Users can:
- Create goals
- Divide them into projects
- Break projects into tasks

As tasks are completed, users earn points and level up, adding a gamification element to productivity.

## 🛠️ Tech Stack

- Python
- Flask
- SQLite
- HTML, CSS, Bootstrap
